Hotel Teste HMAX

Site fictício para validar o embed do motor de reservas HMAX em ambiente STG

Sobre o hotel

Esta é uma página de teste criada para validar o widget <hmax-booking> em domínio externo (GitHub Pages). O conteúdo abaixo simula uma landing page comum de hotel, com o widget embedado como seria no site real do cliente.

Em um hotel real, aqui teria descrição da propriedade, fotos, história, localização etc. O widget abaixo é 100% independente do resto do HTML — carrega via <script> externo e renderiza em Shadow DOM.

⚠️ Antes de testar:
  1. No dash STG, abra a propriedade do hotel que você quer testar.
  2. Aba "Site próprio (Embed)" — habilite o módulo.
  3. Em Domínios autorizados, adicione: desolrac.github.io
  4. No arquivo index.html deste repo, troque SLUG_DO_HOTEL pelo slug real do hotel.
  5. Faça commit + push. Aguarde ~1 min pro GitHub Pages republicar.
  6. Recarregue esta página com Ctrl+F5.
